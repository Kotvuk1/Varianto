# ADR-0004: История для заданий — сервер читает архив data.binance.vision

Статус: принято (2026-11-03). Источник: `ARCHITECTURE.md` C2, §5.2; `PRD.md` FR-DATA-18, OQ-04, OQ-19.

## Контекст
- Задания (Market Structure, Price Action, Challenge) строятся по реальной истории BTCUSDT/ETHUSDT/SOLUSDT; будущее Challenge должно жить на сервере (ADR-0005).
- `fapi` недоступен серверу (ADR-0003). `data.binance.vision` (официальный архив USDⓈ-M) доступен с серверов, но отдаёт файлы без CORS, поэтому браузер читать его не может.
- Проверено curl 2026-11-03: daily klines 1h BTCUSDT за 2026-10-20 — zip 1.5 КБ; monthly klines 1d — zip 2 КБ; daily aggTrades BTCUSDT за сутки — zip около 14 МБ; рядом лежит файл `.CHECKSUM` (sha256); сервер архива поддерживает HTTP Range (ответ S3); CSV содержит строку заголовка; время в миллисекундах. Файл за 2026-11-02 на 2026-11-03 03:08 UTC ещё отсутствовал (404), за 2026-11-01 был.
- Архив публикуется с задержкой около суток (бывает больше).

## Решение
- `ArchiveSource.get(symbol, tf, from, to)` (`packages/market-data`, только сервер): monthly zip для закрытых месяцев, daily zip для текущего месяца; распаковка CSV, проверка заголовка колонок, нормализация в `Candle[]`, `source: 'binance-archive'`.
- Задания строятся только по данным старше 2 суток (запас на задержку публикации).
- Маршрут `GET /api/history` отдаёт нормализованные свечи; ответы за закрытые периоды: `Cache-Control: public, max-age=31536000, s-maxage=31536000, immutable`; запрос выровнен по границам ТФ, чтобы ключ CDN-кэша был стабильным (`API_CONTRACTS.md`).
- Для drill-down Challenge (ADR-0007) сервер читает daily aggTrades; поток распаковывается и обрывается после нужной минуты.
- При отсутствии файла или смене формата — ошибка 502 `archive_unavailable`, без подстановки данных.
- Тесты и фикстуры используют те же файлы (`fixtures/`, с указанием источника и даты, FR-DATA-18).

## Рассмотренные альтернативы
| Вариант | Почему отклонён |
|---|---|
| Предзагруженные фикстуры в репозитории как единственный источник | Ограниченный набор сценариев, раздувание репозитория, нет «случайного момента реальной истории». Фикстуры остаются только для тестов. |
| Загрузка архива браузером | Нет CORS. |
| Свой кэш в БД (Supabase) | Объём свечей несовместим с Free-тарифом; CDN Vercel достаточен для immutable-ответов. |
| fapi через сервер | 451. |

## Последствия
- Плюс: задания не зависят от гео-блока; CDN снимает повторную нагрузку.
- Плюс: официальный источник совпадает с живыми данными Binance по формату.
- Минус: самые свежие данные (последние 2 суток) недоступны для заданий — приемлемо для тренировки.
- Минус: размер daily aggTrades (zip около 14 МБ за сутки BTCUSDT на 2026-10-20, распакованный CSV больше) — риск времени и памяти функции Hobby; нужна потоковая распаковка и замер на M0.
- Минус: формат CSV может измениться; защита — проверка заголовка и контрольной суммы (`.CHECKSUM`), контракт-тесты.
- Открыто: стратегия кэша в браузере для истории заданий и глубина загрузки по ТФ (OQ-19).
