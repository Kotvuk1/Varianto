# Interview Summary — Trading Lab

Дата: 2026-11-03. Статус: **ожидает подтверждения пользователя.**

## 1. Продукт и пользователь
- Пользователь: один (владелец), в будущем возможно несколько. Модель данных сразу многопользовательская.
- Уровень: средний (B) — знает базу, нужна практика на реальных графиках и подробный разбор ошибок; теория — короткими справками внутри заданий.
- Школа анализа: **SMC**.
- Устройства: телефон и ноутбук на равных; интерфейс mobile-first, управление касаниями.

## 2. Модули и приоритеты
| Приоритет | Модуль |
|---|---|
| MVP | Market Structure Analyzer (SMC) |
| MVP | Trading Challenge |
| MVP | Price Action Trainer |

Детальное интервью по Fibonacci и Elliott — перед их этапами.

### Trading Challenge
- Случайный момент реальной истории, дата скрыта; выбор таймфрейма, но без доступа к будущему.
- LONG / SHORT / WAIT; для позиции обязательны SL и TP на графике + обоснование (список причин и текст).
- Проигрывание будущего до SL/TP/лимита времени.
- Разбор: результат в R, оценка качества решения отдельно от исхода, правильная разметка ситуации.
- Сложность: лёгкий (явный тренд, подсказки) / средний (без подсказок) / сложный (флэт, ложные пробои, часто верен WAIT).
- Сценарии генерируются автоматически из истории; правильность = исход + правила структуры.

### Market Structure Analyzer (SMC)
- Режимы: «Разметка» (пользователь размечает, алгоритм сравнивает) и «Вопрос» (быстрые задания).
- Разметка через панель инструментов: выбрать инструмент → тап/протяжка на графике; метки можно двигать и удалять.
- Понятия MVP: Swing High/Low, HH/HL/LH/LL, BOS и CHoCH **по закрытию тела свечи**, внешняя и внутренняя структура, Liquidity sweep, Order Block, FVG.
- Позже: Premium/Discount (в Fibonacci), Inducement (v2).
- Swing — фрактал с N свечами слева и справа (N зависит от сложности); допуск сравнения ±2 свечи (уточняется в архитектуре).

### Price Action Trainer
- Типы заданий: «Найди модель», «Проведи уровень» (допуск ~0.3%), «Контекст» (основной упор).
- Модели MVP: поглощение, пин-бар (молот/падающая звезда), внутренний бар, доджи, утренняя/вечерняя звезда.
- Связь с SMC: контекст модели (sweep, OB, уровень, старший тренд).

### Свободный терминал
- Живой график, все инструменты разметки, разметка сохраняется в аккаунт и синхронизируется между устройствами.
- Кнопка «Проверить мою разметку» — тот же SMC-алгоритм на живом рынке.

## 3. Обратная связь и прогресс
- Правильность всегда определяет **детерминированный алгоритм**.
- MVP: разборы на шаблонах по распознанным ошибкам (что верно, ошибка, почему, как правильно, принцип).
- Позже: кнопка «Спросить ИИ» (Claude API), получающая только проверенные алгоритмом факты.
- Прогресс: точность по каждому навыку, журнал ошибок, адаптивная подборка по слабым местам, статистика Challenge (win rate, средний R, доля верных WAIT), повышение сложности при точности ~80%.
- Главный экран прогресса — «Слабые места».
- Мотивация: ежедневная цель + мягкая серия дней (пропуск одного дня не обнуляет). Без XP, ачивок, рейтингов.

## 4. Интерфейс
- Русский интерфейс, термины SMC на английском с расшифровкой; тексты вынесены для будущей локализации.
- Тёмная тема по умолчанию + светлая.
- Стиль «рабочий терминал»: максимум места графику, минимум декора; проверка через Impeccable.
- **Свечи синие/оранжевые** (монохром как настройка). Красный/зелёный не используются для «победы/поражения»; результаты в R нейтральным цветом; разбор — иконками и формой меток, не «светофором».
- Мобильная раскладка: график на весь экран, инструменты в нижней панели, разбор — нижняя шторка.

## 5. Рыночные данные
- Binance USDⓈ-M Futures. Пары заданий: BTCUSDT, ETHUSDT, SOLUSDT Perpetual. В терминале — любая USDⓈ-M пара.
- Таймфреймы: 15m, 1H, 4H, 1D.
- Индикаторы: **только объём**.
- Binance доступен с устройства пользователя (проверено пользователем). Из облака разработки и, вероятно, с серверов Vercel в США — 451.
- Решение: **рыночные данные загружает браузер напрямую** (REST + WebSocket, CORS разрешён); Vercel отдаёт сайт и хранит прогресс. Для разработки и тестов — официальный архив data.binance.vision.

## 6. Стек и инфраструктура
- Next.js + TypeScript на Vercel (Hobby).
- TradingView Lightweight Charts + собственный слой разметки (объекты с привязкой к времени/цене, сохраняются в Supabase, рендер через плагины/примитивы).
- Логика SMC / Price Action — отдельная чистая TS-библиотека с тестами (общая для браузера и сервера).
- Supabase Free: Postgres + авторизация (Google + magic link по email); автопинг против засыпания.
- Бюджет: только бесплатные тарифы; переход на платные — настройкой.

## 7. Процесс
- Поэтапные Pull Request'ы с превью-ссылкой Vercel; в `main` вливает пользователь.
- Решения фиксируются в ADR (`docs/DECISIONS/`).

## Открытые вопросы (решаются в архитектуре)
- Подтвердить загрузку Binance из браузера на телефоне пользователя (прототип).
- Точные параметры алгоритмов (N фрактала, допуски, правила OB/FVG/sweep) — с Technical Analyst, с тестами на реальных данных.
- Подключение репозитория к Vercel и создание проекта Supabase (требует действий пользователя).
