# LAYOUTS — Trading Lab

Версия 0.1. Раскладки на двух опорных размерах: мобильный 390x844 (проверка до 360x640) и десктоп 1440x900. Токены — `tokens.css`, компоненты — `COMPONENTS.md`, тексты — `COPY.md`. Данные в схемах условные; на скриншотах реализации подпись источника данных обязательна.

## 0. Общие правила

### 0.1 Навигация и уровни
Три раздела: Терминал, Обучение, Прогресс. «Обучение» — стартовый экран (Главная): продолжить, слабые места, цель дня, три модуля (Market Structure, Price Action, Trading Challenge). Глубина: раздел -> сессия (график). Настройки и вход — иконка в верхней панели, диалог/шторка, не раздел.

Мобильный:
- Экраны без графика (Обучение, Прогресс): нижняя панель вкладок 56 px: Терминал, Обучение, Прогресс (иконка 24 + подпись 12 px, цель 130x56).
- Экраны с графиком (Терминал, сессия): вкладки скрыты, нижнюю зону занимает панель инструментов; навигация — кнопка `menu` слева в верхней панели (открывает список разделов шторкой) и `arrow-left` в сессии заданий.
Десктоп: верхняя панель 48 px с вкладками раздела; на экранах с графиком слева рейка инструментов 56 px, справа панель 360 px.

### 0.2 Зоны экрана 390x844
```
y=0     верхняя панель                        48
        строка контекста (задание/ТФ)         40 (по необходимости)
        ───────────────────────────────────────
        ГРАФИК                                ~610 (весь остаток)
        ───────────────────────────────────────
        нижняя панель инструментов            56
        safe-area-inset-bottom                0–34
y=844
```
Высота графика на 390x844 с контекстной строкой: 844 - 48 - 40 - 56 - 34 = 666; без контекстной строки 706. Оси цены/времени внутри графика, не добавляют высоты. На высоте < 700 (альбом, 360x640) контекстная строка сворачивается в верхнюю панель, нижняя панель остаётся.

### 0.3 Жесты и разметка (мобильный)
Без активного инструмента: один палец — прокрутка, два — масштаб, долгое касание — перекрестие с OHLCV (FR-CHART-02..04). С активным инструментом: тап ставит точку/метку; протяжка рисует зону/линию; чтобы листать график, переключитесь на «Выбор» или используйте двухпальцевый жест (двумя пальцами листание и масштаб работают всегда). Активный инструмент виден: выбранная кнопка залита accent, в контекстной строке подсказка «BOS: коснитесь свечи, закрывшейся за уровнем». Инструмент остаётся включённым после постановки метки (серия); выход — «Выбор» или повторный тап по кнопке.
Выбранный объект: ручки 12 px с областью 44x44, рядом мини-панель действий: `trash-2` Удалить, `x` Снять выбор (область 44x44, над объектом, не перекрывает ручки).

Пара: тап на «BTCUSDT ▾» открывает шторку выбора пары: поле поиска (autofocus, 16 px), список «Недавние» и «Все USDⓈ-M», строка 48 px. ТФ: Segmented 4 сегмента по 44x40 (визуально 40 по высоте, цель 44 за счёт внешнего отступа); смена ТФ сохраняет центр и ширину видимого времени (FR-CHART-05), метки остаются на месте.
Незакрытая свеча: пунктирный контур + бейдж «Идёт» над ней; проверка использует только закрытые (FR-TERM-08).

## 4. Bottom sheet разбора (6 частей)

### 4.1 Мобильный
Три высоты: свёрнутая (peek) 120 px, средняя 50% экрана (по умолчанию после проверки), полная 90%. Ручка 40x4 по центру, вся строка заголовка 48 px является зоной перетаскивания; кнопки закрытия `x` и сворачивания `chevron-down` 44x44. На средней высоте график виден в верхней половине (~380 px), сохраняется скролл/масштаб графика.
```
┌──────────────────────────────────────┐
│               ━━━━                   │ ручка
│ Разбор                    [Эталон][x]│ 48: заголовок; переключатель «Эталон» (eye) показывает/скрывает метки алгоритма
├──────────────────────────────────────┤
│ 1  Результат                         │  итоговая строка:
│    ● Совпало 5   ◌ Пропущено 2   ■ Лишнее 1   │  число + форма + слово
│ ──────────────────────────────────── │
│ 2  Что верно                         │
│    ● Swing High на 14:00             │  строки по 44, иконка круг-галочка,
│    ● BOS на 16:00           [показать]│  [показать] фокусирует график на метке
│ 3  Ошибки                            │
│    ◌ CHoCH на 17:00 не отмечен       │  пунктирный круг
│    ■ Лишний OB на 12:00              │  квадрат-крест
│ 4  Почему это ошибка                 │  абзац 16/24 (шаблон по типу ошибки)
│ 5  Как правильно                     │  абзац + [Показать эталон на графике]
│ 6  Принцип                           │  1–2 предложения; термины с (i)
├──────────────────────────────────────┤
│ [ Следующее задание ]   [ Повторить ] │ закреплено внизу шторки, 48 px
└──────────────────────────────────────┘
```
Названия частей (фиксированный порядок, FR-FB-02): 1 «Верно ли», 2 «Что понято верно», 3 «Ошибки», 4 «Почему это ошибка», 5 «Как правильно», 6 «Принцип». Первая часть — вывод одной строкой («Верно частично: 5 из 8»), не оценка цветом. Нумерация цифрами в кружке нейтрального цвета (контур `--border-strong`). Если ошибок нет, части 3–5 заменяются строкой «Ошибок не найдено» (часть 6 остаётся).
Метки в списках и на графике связаны: тап по строке выделяет метку, график центрируется на ней (с учётом высоты шторки: центр видимой области графика над шторкой).
Тап по метке на графике скроллит шторку к строке.

### 4.2 Десктоп
Те же шесть частей в правой панели 360 px (высота панели, прокрутка внутри, закрепленный низ с кнопками). Шторка не используется. Частям 3–5 соответствуют метки на графике; при наведении строки метка подсвечивается (утолщение контура, не цвет).

## 5. Trading Challenge

Фазы: Выбор сложности -> Решение -> Подтверждение -> Проигрывание -> Итог.

### 5.1 Мобильный 390x844

Выбор сложности (экран без графика, вкладки видны):
```
│ Trading Challenge                    │
│ Сложность                            │
│ (•) Лёгкий   явный тренд, подсказки  │ радио-строки 64 px
│ ( ) Средний  без подсказок           │
│ ( ) Сложный  флэт, ложные пробои     │
│ [ Начать сценарий ]                  │
```
Решение:
```
┌──────────────────────────────────────┐
│ [<] Challenge · Лёгкий      [15m 1H 4H 1D] 48   смена ТФ без доступа к будущему
├──────────────────────────────────────┤
│ BTCUSDT · дата скрыта                │ 32
│                                      │
│  TP ─────────────────── 65 400 (+2R) │  сплошная линия, плашка «TP» + цель
│  вход ┄┄┄┄┄┄┄┄┄┄┄┄┄┄ 64 380          │  точечная
│  SL ─ ─ ─ ─ ─ ─ ─ ─ ─ 63 870 (-1R)  │  штриховая, плашка «SL» + щит
│               ГРАФИК                 │ ~560
│                                      │
├──────────────────────────────────────┤
│ SL 63 870 · TP 65 400 · R:R 1:3      │ 32  сводка (нейтральный цвет)
├──────────────────────────────────────┤
│ [ LONG ] [ SHORT ] [ WAIT ]          │ 56  Segmented на 3, выбор = залитый accent
├──────────────────────────────────────┤
│ [ Причины и подтверждение ]          │ 48  accent, активна при SL+TP (или WAIT)
└──────────────────────────────────────┘
```
Установка SL/TP: после выбора LONG/SHORT на графике появляются линии входа (цена закрытия последней свечи), SL и TP со значениями по умолчанию (по ATR, 1R/2R); их двигают перетаскиванием за ручку (цель 44x44) по вертикали; дробные цены привязываются к шагу тика пары. Параметры SL/TP также редактируются числом в сводке (тап по значению открывает поле). Если SL/TP не заданы или в неверную сторону — кнопка «Причины и подтверждение» неактивна, под ней причина текстом (FR-FB-09): «Поставьте SL ниже входа для LONG».
Причины (шторка при нажатии «Причины и подтверждение», средняя высота):
```
│ Обоснование                       [x]│
│ Выберите причины (1+):               │
│ [BOS вверх][CHoCH][Sweep ликвидности]│ чипы-тоггл 44 px, перенос строк
│ [Order Block][FVG][Уровень][Тренд]   │ выбранный: залит accent + галочка
│ [Старший ТФ][Другое]                 │
│ Комментарий (необязательно)          │
│ ┌──────────────────────────────────┐ │ textarea 3 строки, 16 px
│ └──────────────────────────────────┘ │
│ [ Подтвердить ]                      │ 48
```
Для WAIT чипы другие: «Нет явной структуры», «Жду сбор ликвидности», «Цена в середине диапазона», «Неблагоприятный R:R», «Другое».
Проигрывание (панель инструментов заменена контролями):
```
├──────────────────────────────────────┤
│ Идёт сценарий · свеча 14 из 60       │ 32  статус (aria-live polite)
│ [Пауза] [ 1× ][ 2× ][ 4× ] [До конца] │ 56  кнопки 56x44; выбранная скорость залита
```
Свечи появляются справа; график автоматически следует за последней свечой, любой жест прокрутки ставит паузу следования (кнопка `locate-fixed` «К последней свече» появляется). Остановка на SL/TP/лимите: текст «Сработал TP» или «Сработал SL» (без цвета) -> автоматически открывается итог.
Итог (шторка, 90% высоты; график сверху показывает ход цены и дату сценария):
```
│ Итог                              [x]│
│ Исход                    Решение     │  две Stat 50/50, без цветовой оценки
│ +2.0 R                   4 из 5      │  text-2xl 600, text-1
│ позиция закрыта по TP    критериев   │
│ Дата сценария: 14 марта 2025, 14:00  │
│ ───────────────────────────────────  │
│ Разбор (6 частей, как в §4)          │  Заголовок «Решение отдельно от исхода»:
│ ...                                  │  можно верно решить и получить -1R
│ [ Следующий сценарий ] [ Выйти ]     │
```
R показывается со знаком и цветом `--text-1`. Если SL и TP сработали в одной свече — строка с иконкой `info` «SL и TP в одной свече: порядок определён по 15m» и кнопка «Показать на 15m».
WAIT: итог «Исход: WAIT был верным / не был верным» формулировкой и иконкой формы (круг с галочкой / квадрат с крестом), R не показывается («—»).
Десктоп 1440x900: правая панель 360 px содержит этапы по очереди: Решение (LONG/SHORT/WAIT + сводка SL/TP + причины чипами + комментарий + «Подтвердить»), затем контролы проигрывания (Play/Пауза, скорость, «До конца») над списком событий, затем Итог и разбор. Рейка слева содержит только Выбор и Ластик (позиция ставится через панель, а не рейкой).

## 8. Состояния экрана (FR-UI-08)

Каждый экран с данными имеет четыре состояния: загрузка, пусто, ошибка, офлайн. Тексты — `COPY.md`. Состояния не окрашиваются; различаются иконкой, заголовком и действием.

### 8.1 Загрузка
График: пустая область графика без сетки с шкалой скелетона (3 горизонтальные полосы `--surface-2`), по центру текст «Загружаю свечи BTCUSDT 1H…» и `aria-busy="true"`; панели инструментов и верхняя панель доступны, инструменты неактивны (`aria-disabled`). Если свечи загружаются дольше 8 с — добавляется «Это дольше обычного» и кнопка «Отмена». Списки: 3 строки скелетона высотой как у реальных; без анимации блеска (при `prefers-reduced-motion` вообще статично).
```
┌──────────────────────────────────────┐
│ [≡] [BTCUSDT ▾]  [15m 1H 4H 1D]  [Настр] │
│                                      │
│         ▭▭▭▭▭▭▭▭▭▭▭▭▭                │
│         Загружаю свечи BTCUSDT 1H…   │
│                                      │
│ [↖][Структура][Зоны][Линии][⌫][Проверить] (неактивны)
```

### 8.2 Ошибка Binance (451, сеть, 5xx, архив)
Блок на месте графика (не тост): иконка `triangle-alert` 24 px (нейтральная), заголовок, 1–2 строки причины и что делать, кнопки. Верхняя панель и вкладки остаются.
```
│            (!)                        │
│  Binance недоступен из вашей сети     │ заголовок text-lg
│  Сервер ответил 451: доступ ограничен │ text-sm text-2
│  по региону. Включите VPN или         │
│  откройте сайт с другого устройства.  │
│  [ Повторить ]   [ Подробности ]      │ первичная + вторичная, 48 px
```
Разные причины — разные заголовки: 451 (регион), нет сети (офлайн), 429/5xx (временная недоступность Binance), архив data.binance.vision недоступен (задания). Если есть кэш свечей — график показывается из кэша с полосой-уведомлением над ним (§8.4), а не блок-ошибка. Коды и технические подробности — под раскрывающейся «Подробности» (код ответа, URL хоста, время), не в заголовке.
WebSocket оборвался: график остаётся, в верхней панели бейдж «Нет живых данных» (иконка `wifi-off`) и автоматический REST-опрос; при восстановлении бейдж пропадает без тоста.

### 8.3 Пустые состояния
- Прогресс/Слабые места, нет попыток: заголовок «Пока нет данных», текст «Решите первое задание — здесь появятся навыки, требующие внимания», кнопка «Начать Market Structure». Без иллюстраций.
- Журнал ошибок пуст: «Ошибок пока нет».
- Терминал, нет разметки: подсказка в правой панели «Выберите инструмент слева и коснитесь графика»; на мобильном — одноразовая подсказка над панелью (не блокирует).
- Challenge, нет сценариев в выбранной сложности: «Нет подходящих сценариев» + «Сменить сложность».
- Поиск пары без результатов: «Пара не найдена. Проверьте тикер, например BTCUSDT».
- Список меток пуст: «Меток нет».

### 8.4 Офлайн
Полоса над графиком (высота 32, `--surface-2`, иконка `wifi-off`): «Нет сети. Показаны сохранённые данные». На графике — кэшированные свечи, инструменты разметки работают локально, «Проверить» работает по кэшу (алгоритм в браузере); сохранение в аккаунт — отложено, в полосе «Разметка сохранится при подключении». Без кэша: блок-ошибка §8.2 «Нет сети». Возврат сети: полоса исчезает, тост не показывается. Challenge и новые задания, требующие свежей истории, недоступны офлайн (кнопки неактивны с пояснением).

### 8.5 Ошибки ввода в заданиях
Не блокирующие диалоги, а поясняющая строка у кнопки и фокус на проблемном месте: «Поставьте SL: без него нельзя подтвердить позицию», «SL должен быть ниже входа для LONG», «Выберите хотя бы одну причину».

## 9. Адаптивность и границы

| Ширина | Раскладка |
|---|---|
| 360–599 | мобильная: нижняя панель инструментов, шторка |
| 600–1023 | планшет: мобильная раскладка, шторка до 480 px по ширине, график по центру; в альбоме правая панель 320 px вместо шторки |
| >= 1024 | десктоп: рейка 56 + график + панель 360 |
| >= 1440 | та же, график шире; контент неграфических экранов max-width 1280 |

Горизонтальной прокрутки страницы нет (NFR-RESP-02): длинные таблицы превращаются в строки-списки на < 600; тикеры/цены не переносятся (`white-space: nowrap`), текст переносится. Поддерживается альбомная ориентация телефона (844x390): верхняя панель 40, контекстная строка скрыта, нижняя панель 48, шторка заменяется правой панелью 320 px.
