# COMPONENTS — Trading Lab

Версия 0.1. Токены — `tokens.css`; экраны — `LAYOUTS.md`; тексты — `COPY.md`. Реализация (Frontend/Chart) выбирает имена пропсов; ниже — контракт внешнего вида и поведения.

## 0. Общее

Состояния всех интерактивных компонентов (если не оговорено иное):

| Состояние | Правило |
|---|---|
| default | фон по варианту, граница `--border-strong` где нужна распознаваемость |
| hover (pointer: fine) | фон на один шаг светлее/темнее (surface-1 -> surface-2; accent -> `--accent-hover`); без сдвигов и теней |
| active (нажатие) | фон `--surface-2` (или accent тоном темнее), без анимации масштабирования; реакция в 100 мс |
| focus-visible | двойное кольцо: 2 px `--focus`, отступ 2 px, подложка 4 px `--bg`; не убирается нигде |
| disabled | `aria-disabled="true"`, цвет текста `--text-3`, граница `--border`; остаётся в фокус-порядке, если причина важна (Tooltip объясняет причину); `disabled` атрибут — только когда объяснять нечего |
| loading | текст сохраняется, спиннер заменяет иконку слева, `aria-busy`, повторный клик блокируется |

Размеры: минимальная цель 44x44 (`--hit`). Текстовые кнопки при `pointer: fine` — 36. Иконки 20 px (`stroke-width 1.75`) в UI, 24 px в нижней панели вкладок и ToolButton, 16 px внутри меток графика и бейджей. Все иконки — lucide-react (один набор). Иконка без подписи обязана иметь `aria-label` и Tooltip на pointer: fine.
Нельзя: цветные плитки под иконкой, иконка над заголовком раздела, градиентные кнопки, внутренняя тень, glow при фокусе.

## 1. Набор иконок: lucide-react

Версия фиксируется в `package.json`; импорт по имени (`import { Eraser } from "lucide-react"`), без динамической загрузки всего набора. Если названной иконки нет в установленной версии — взять ближайшую из набора и записать замену здесь; custom SVG допускается только в стиле lucide (24x24, stroke 1.75, round caps) и лежит в `src/components/icons/`.

### 1.2 Остальные иконки

Навигация: `menu` (открыть разделы), `arrow-left` (назад в сессии), `settings`, `user` (вход/профиль), `log-out`, `chevron-down`/`chevron-right` (раскрытие/переход), `x` (закрыть), `search` (поиск пары), `panel-right-close`/`panel-right-open` (панель на десктопе).
Раздел: Терминал — `candlestick-chart` (имя в новых версиях `chart-candlestick`), Обучение — `book-open`, Прогресс — `chart-no-axes-column`.
Состояния разбора: `circle-check` (совпало), `circle-dashed` (пропущено), `square-x` (лишнее), `eye`/`eye-off` (показать/скрыть эталон), `scan-search` («Проверить»).
Системные: `triangle-alert` (ошибка загрузки; нейтральный цвет), `wifi-off` (офлайн, нет живых данных), `info` (справка), `circle-help` (определение термина), `refresh-cw` (повторить), `locate-fixed` (к последней свече).
Challenge: `play`, `pause`, `fast-forward`, `skip-forward` (до конца).
Правила: иконка всегда рядом с текстом, кроме ToolButton с подсказкой, закрытия и стрелок; красный/зелёный не применяются; для различия «верно/неверно» формы фиксированы (круг-галочка / пунктирный круг / квадрат-крест).

## 2. Компоненты

### 2.1 Button
Варианты: primary (фон `--accent`, текст `--on-accent`) — одно на экран/шторку; secondary (прозрачный фон, граница `--border-strong`, текст `--text-1`); tertiary/ghost (без границы, текст `--text-1`, hover `--surface-2`). Размеры: lg 48 (мобильный CTA), md 44 (по умолчанию на touch), sm 36 (только pointer: fine). Ширина: в нижних зонах мобильного — на всю ширину или половина; отступ от края 12. Радиус 8, текст 14/500, иконка слева 20 px. Нет «опасной» красной кнопки: «Удалить метку» — secondary с иконкой `trash-2`, подтверждение не нужно (метки восстанавливаются отменой на десктопе; на мобильном удаление мгновенное, Toast «Метка удалена» c «Вернуть»).
Использование: в сессии «Проверить» — primary; «Следующее задание» — primary в шторке, «Повторить» — secondary. Два primary рядом запрещены.

### 2.2 IconButton
44x44 (touch), 36x36 визуально допустимо при pointer: fine с внешней областью 44. Иконка 20. Состояние «нажат/включён» (toggle): `aria-pressed`, фон `--surface-2` + граница `--border-strong` (не accent — accent зарезервирован для основного действия и выбранного инструмента). Обязательны `aria-label` и Tooltip.

### 2.3 Segmented (таймфрейм, сложность, тема)
Сегменты 15m / 1H / 4H / 1D (ТФ), равной ширины, высота визуально 36, цель 44 (внешний padding кнопок). Контейнер: граница `--border-strong`, радиус 8; выбранный сегмент: фон `--accent`, текст `--on-accent`; остальные прозрачные. `role="radiogroup"`, стрелки влево/вправо переключают. На 360 px четыре сегмента по 44 = 176 — помещаются. Выбор ТФ не перезагружает страницу и сохраняет центр/ширину видимого времени. Disabled-сегмент (например, нет данных этого ТФ) остаётся видимым с `--text-3`.

### 2.4 Select (пара)
Закрытый вид: кнопка со значением («BTCUSDT»), `chevron-down`, высота 44, ширина по содержимому (min 112). Открытие: мобильный — BottomSheet с полем поиска, десктоп — поповер 320x420 под кнопкой. Поле поиска: 16 px, `search`, autofocus, очистка `x`. Список: секции «Недавние» (до 5) и «Все USDⓈ-M»; строка 48: тикер (`text-sm` 500) + название базового актива (`text-xs text-2`). Клавиатура: стрелки, Enter, Esc. Пустой результат -> состояние «Пара не найдена». Загрузка списка -> скелетон 6 строк. Для заданий (BTC/ETH/SOL) пара задана заданием — Select отображается как статичный текст без стрелки.

### 2.5 Toolbar + ToolButton
Toolbar мобильная: фиксирована снизу, высота 56 + safe-area, фон `--surface-1`, верхняя граница 1 px `--border`. Содержит 5 ToolButton-групп и CTA. Десктопная рейка: столбец 56 px, разделители между группами 1 px `--border`, отступ 4.
ToolButton: 48x56 (мобильный) / 44x44 (рейка); иконка 24 + подпись 12 px под иконкой (мобильный; на 360 подпись скрывается). Состояния: default — иконка `--text-2`; hover — `--text-1`; active/selected — фон `--accent`, иконка `--on-accent`, `aria-pressed="true"`; focus — кольцо; disabled — `--text-3`, tooltip с причиной («Загрузка свечей…»). Группа с вееером: индикатор «есть вложенные» — маленький треугольник в правом нижнем углу (4 px); показывает иконку последнего выбранного инструмента группы. Веер: полоса над панелью (56 px, `--surface-2`, граница сверху, прокрутка по горизонтали), ToolButton 56x56.
Правило: выбранный инструмент всегда виден (в панели и в строке контекста с подсказкой). Нет вложенного поповера внутри поповера.

### 2.6 BottomSheet
Модальность: разбор и итог — немодальные до половины высоты (график над ними интерактивен), модальные при 90% (скрим `--scrim`). Выбор пары, настройки, причины — модальные. Высоты: peek 120, medium 50%, full 90%, максимум `100dvh - 48`. Ручка 40x4 `--border-strong` (область 44 по высоте), верхние углы 12, фон `--surface-2`, тень `--shadow-raised`. Заголовок 48 (`text-lg` 600), кнопка `x` 44x44 справа. Закрепленный низ с кнопками (primary + secondary), внутренняя прокрутка. Закрытие: `x`, свайп вниз по ручке/заголовку, Esc, тап по скриму (для модальной). Фокус: при открытии на заголовок, при закрытии возвращается на вызвавшую кнопку. `role="dialog"`, `aria-labelledby`. Анимация: translateY 240 мс ease-out; при reduced-motion — мгновенно. Жест свайпа не конфликтует с прокруткой содержимого: перетаскивание только за ручку/заголовок.

### 2.7 Chip
Тоггл-чипы причин Challenge и фильтры. Высота 44 (визуально 36 + внешний отступ), горизонтальный padding 12, радиус 4, текст 14. Default: граница `--border-strong`, фон прозрачный. Selected: фон `--accent`, текст `--on-accent`, иконка `check` 16 слева (выбор различим не только цветом). `role="checkbox"`/`aria-pressed`. Disabled — `--text-3`. Перенос строк, отступ между чипами 8.

### 2.8 Badge
Не интерактивный; высота 20, padding 8, радиус 4, `text-xs` 500. Варианты: neutral (фон `--surface-2`, текст `--text-2`), outline (граница `--border-strong`). Применение: «Идёт» (незакрытая свеча), «Нет живых данных» (с иконкой `wifi-off`), ТФ-метка. Нет цветных бейджей успеха/ошибки. Не использовать как кнопку.

### 2.9 Stat
Пара «значение + подпись»: значение `text-2xl` 600 `tnum` цветом `--text-1`; подпись `text-xs` `--text-2` сверху или снизу. Опционально единица (`R`, `%`) `text-sm` `--text-2`. Знак: «+2.0 R» / «-1.0 R» — только знаком, цвет не меняется. Без рамки; группа Stat разделена вертикальной линией `--border` или просто отступом. Не вкладывать в карточку.

### 2.10 ProgressBar
Высота 6 (мобильный список) / 8 (цель дня), радиус 4; дорожка `--surface-2`, заполнение `--accent` (в светлой теме — `--accent`). `role="progressbar"` с `aria-valuenow/min/max`; подпись числом обязательна («6 из 10»), бар вторичен. Точность навыка отображается тем же баром, одним цветом независимо от значения (без цветовых порогов). Анимация заполнения отсутствует.

### 2.11 Toast
Только для результата действия пользователя (создано/удалено/сохранено/скопировано). Позиция: мобильный — над нижней панелью (отступ 8), десктоп — внизу слева от панели. Ширина по содержимому, max 360, `--surface-2`, граница `--border-strong`, тень `--shadow-raised`. Автозакрытие 4 с (6 с если есть действие «Вернуть»); пауза при hover/focus; `role="status"` (`aria-live="polite"`); не более одного одновременно. Нельзя использовать для ошибок загрузки и критичных состояний (они — блок на экране).

### 2.12 Tooltip / Hint
Tooltip (pointer: fine): появляется после 400 мс hover и сразу при фокусе с клавиатуры; один-два слова + горячая клавиша; `role="tooltip"`; не содержит интерактива. Hint (касание): определение термина SMC по нажатию на термин (`BOS` с пунктирным подчёркиванием `text-decoration: underline dotted`) — открывает поповер (десктоп) или мини-шторку (мобильный) с определением 1–2 предложения из `COPY.md` §6 и кнопкой «Закрыть». Термин получает подчёркивание только при первом упоминании на экране и в справке задания; далее — обычный текст. Подсказка активного инструмента — строка контекста (не Tooltip).

### 2.13 FeedbackBlock (разбор)
Контейнер шести частей разбора (в BottomSheet на мобильном, в боковой панели на десктопе). Структура фиксирована (FR-FB-02): 1 Верно ли, 2 Что понято верно, 3 Ошибки, 4 Почему это ошибка, 5 Как правильно, 6 Принцип. Каждая часть: номер в кружке (контур `--border-strong`, цифра `--text-1`), заголовок `text-sm` 600, тело. Части 2 и 3 — списки FeedbackItem: строка высотой >= 44, слева маркер состояния (иконка+форма из DESIGN §2.3: `circle-check` / `circle-dashed` / `square-x`) 24 px, текст «Тип, время/цена: что произошло», справа кнопка «Показать» (`locate-fixed`, 44x44) и состояние выбора. Части 4–6 — текст (`text-base`), термины подсвечены для Hint. Нумерация и заголовки частей остаются для скринридера (`<ol>`), раскрываемые секции (`details`) для 4–6 на мобильном при peek; на medium/full раскрыты. Итоговая строка (часть 1): «Верно частично: 5 из 8» — текст, нейтральный цвет.
Состояния: loading (скелетон 6 строк, текст «Сверяю с эталоном…»), empty (нет ошибок: части 3–5 заменены строкой «Ошибок не найдено»), error («Не удалось получить разбор» + «Повторить»; разметка пользователя сохраняется).

### 2.14 Прочие (по необходимости, не расширять без решения)
- ListRow: строка списка (слабые места, журнал, пары) высота 56, заголовок + вторичная строка + `chevron-right`; граница снизу 1 px `--border`.
- Notice: полоса уведомления (офлайн, нет живых данных): высота 32, `--surface-2`, иконка, один текст.
- ChartStatus: блок состояний графика (загрузка/ошибка/пусто) по LAYOUTS §8.
- TabBar: нижние вкладки на мобильном (3 шт., 130x56, иконка 24 + подпись 12; выбранная вкладка: иконка и текст `--text-1`, 2 px полоса сверху `--accent`; невыбранная `--text-2`).
- Dialog (десктоп, настройки): 480 px, те же правила, что BottomSheet.

| Метка | Визуал | Подпись | Ручки |

Владелец: user — плашка залита `--mark-user`, текст `--mark-user-on`; algo — плашка с контуром `--mark-algo`, прозрачная, текст `--mark-algo`. Подпись метки 12 px/500. Контуры линий имеют полупрозрачный ореол цвета фона 2 px (чтобы читались поверх свечей любого цвета). Область касания каждой ручки и линии >= 44 px (FR-DRAW-14). Выбранный объект: контур толще (2 px) + ручки 12 px залитые, мини-панель действий. Перекрытия: подписи смещаются, не перекрывая свечи в зоне последних 10 штук.
Свечи: тело 100% непрозрачное, фитиль 1 px; бычья/медвежья из токенов; в монохроме бычья полая (контур 1.5 px), медвежья заполненная серая. Объём: гистограмма в нижних 15% высоты, цвета `--volume-*`, без собственной шкалы. Последняя цена: линия-пунктир + плашка на оси `--chart-last-price-*`. Оси и перекрестие используют `--chart-*`, шрифт `--font-mono` 11–12 px.
