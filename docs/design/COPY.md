Версия 0.1. Все строки хранятся в `src/i18n/ru` (FR-UI-03); ключи — предложение Frontend, ниже даны тексты. Голос: спокойный, прямой, на «вы», без восклицаний, без оценочных слов («отлично», «увы»), без эмодзи. Кнопки — глагол в инфинитиве или повелительном наклонении («Проверить», «Повторить»). ## 6. Короткие определения терминов (Hint при первом упоминании)

Формат: Термин (расшифровка) — определение 1–2 предложения. Определения учебные; алгоритмические параметры (N фрактала, допуски) не указываются, их фиксирует `ALGORITHMS.md`. Согласовать с Technical Analyst.

| Термин | Определение |
|---|---|
| SMC (Smart Money Concepts) | Подход к чтению графика через следы крупных участников: структуру, ликвидность и зоны интереса. |
| Swing High / Swing Low (свинг-максимум / свинг-минимум) | Локальный экстремум: свеча, максимум (минимум) которой выше (ниже) соседних свечей слева и справа. |
| HH / HL / LH / LL | Higher High, Higher Low, Lower High, Lower Low: каждый новый свинг выше или ниже предыдущего того же типа. Показывают направление структуры. |
| Market Structure (рыночная структура) | Последовательность свингов. Восходящая — HH и HL, нисходящая — LH и LL. |
| Внешняя / внутренняя структура | Внешняя образована крупными свингами старшего движения, внутренняя — мелкими свингами внутри него. |
| BOS (Break of Structure, слом структуры) | Закрытие тела свечи за последним свингом по направлению тренда. Показывает продолжение движения. |
| CHoCH (Change of Character, смена характера) | Закрытие тела свечи за последним свингом против тренда. Первый признак возможного разворота. |
| Liquidity (ликвидность) | Скопление стоп-ордеров и ожидаемых заявок, обычно за очевидными максимумами и минимумами. |
| Liquidity sweep (сбор ликвидности) | Цена выходит за экстремум фитилём, забирает стопы и закрывается обратно по другую сторону уровня: под swing high или над swing low. |
| Order Block (OB, ордерблок) | Последняя противоположная свеча перед сильным импульсом, который сломал структуру. Зона, где цена часто реагирует при возврате. |
| FVG (Fair Value Gap, имбаланс) | Разрыв между тенями первой и третьей свечи трёх подряд идущих, не перекрытый второй свечой. Зона, которую цена нередко возвращается заполнить. |
| Premium / Discount | Верхняя и нижняя половина диапазона. Покупки ищут в Discount, продажи в Premium (после MVP). |
| Inducement | Ложный локальный пробой, провоцирующий вход трейдеров до настоящего движения (после MVP). |
| SL (Stop Loss) | Цена, при которой позиция закрывается с убытком. Ограничивает риск сделки. |
| TP (Take Profit) | Цена, при которой позиция закрывается с прибылью. |
| R (риск) | Единица результата: 1R равен расстоянию от входа до SL. Результат +2R значит, что прибыль вдвое больше риска. |
| R:R | Отношение потенциальной прибыли к риску: 1:3 — цель втрое дальше стопа. |
| LONG / SHORT / WAIT | LONG — ставка на рост, SHORT — на падение, WAIT — осознанный пропуск сделки, когда явного сетапа нет. |
| Закрытая свеча | Свеча, период которой завершён. SMC-проверка использует только закрытые свечи. |
| Pin bar (пин-бар) | Свеча с длинной тенью и маленьким телом: рынок отверг уровень. Молот и падающая звезда — его виды. |
| Engulfing (поглощение) | Свеча, тело которой полностью перекрывает тело предыдущей. |
| Inside bar (внутренний бар) | Свеча, диапазон которой целиком внутри диапазона предыдущей. Сигнал паузы. |
| Doji (доджи) | Свеча, у которой открытие и закрытие почти равны. Нерешительность рынка. |
| Morning / Evening star (утренняя / вечерняя звезда) | Трёхсвечная модель разворота: сильная свеча, маленькая свеча, сильная свеча в обратную сторону. |

## 7. Справки по заданиям (над графиком, одна строка + раскрытие)

| Задание | Текст |
|---|---|
| Swing | Отметьте все Swing High и Swing Low на графике. |
| HH/HL/LH/LL | Подпишите структуру: HH, HL, LH или LL. |
| BOS | Отметьте свечи, где произошёл BOS. Считается закрытие тела, не фитиль. |
| CHoCH | Отметьте свечу, где структура сменила характер. Считается закрытие тела. |
| Sweep | Отметьте свечу, которая собрала ликвидность. |
| Order Block | Выделите Order Block, с которого начался импульс. |
| FVG | Выделите FVG — разрыв между свечами. |
| Проведи уровень | Проведите уровень, от которого цена реагировала. Допуск около 0.3%. |
| Контекст | Определите контекст свечной модели: сбор ликвидности, ближайший Order Block, уровень и старший тренд. |
| Challenge | Примите решение по виду графика без будущего. Для позиции нужны SL и TP. |

## 8. Причины решения в Challenge (чипы)

LONG/SHORT: BOS в сторону сделки · CHoCH · Liquidity sweep · Order Block · FVG · Уровень · Старший тренд · Выгодный R:R · Другое.
WAIT: Нет явной структуры · Жду Liquidity sweep · Цена в середине диапазона · Невыгодный R:R · Другое.
Поле комментария: заголовок «Комментарий», плейсхолдер «Почему вы так решили (необязательно)».

## 9. Правила текста разбора (для шаблонов, см. FR-FB-03)

- Часть 1: один факт и числа, без оценочных прилагательных. «Верно частично: 5 из 8».
- Часть 2: «Верно: BOS на 16:00». Конкретика (тип, время), без похвалы.
- Часть 3: «Не отмечен: CHoCH на 17:00» · «Лишнее: Order Block на 12:00» · «Смещено: Swing High на 14:00 (на 3 свечи)».
- Часть 4 (почему): причина по правилу, без обвинения. «CHoCH фиксируется по закрытию тела свечи за свингом. Цена закрылась за свингом на 17:00, поэтому структура изменилась.»
- Часть 5 (как правильно): действие. «Отметьте CHoCH на свече 17:00, где тело закрылось ниже последнего HL.»
- Часть 6 (принцип): общее правило в 1–2 предложения. «Структуру меняет закрытие тела, а не прокол фитилём.»
- Запрещены: «молодец», «ошибка новичка», «к сожалению», «неудача», «победа», «поражение», «проигрыш», «выигрыш». Исход сделки: «Позиция закрыта по TP: +2.0 R».
- Слова «верно/неверно» подкрепляются формой метки; слово «ошибка» допустимо, «провал» — нет.
- Для скринридера состояния читаются словами («Совпало», «Пропущено», «Лишнее»), не иконками.
